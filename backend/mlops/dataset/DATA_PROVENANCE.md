# MetronIQ Dataset Provenance

## Compliance Record
Ensure every batch of images ingested physically adheres to this log. Copyrighted or unlicensed images cannot be merged into the domain dataset cleanly without record.

### Batch Details Template
- **Source**: (e.g., Internal Physical Capture, Unsplash Public Domain, Permitted Commercial Extract)
- **License/Permission**: (e.g., CC0, Staff-Generated Internal, explicit permission)
- **Date Obtained**: YYYY-MM-DD
- **Category**: (e.g., Snack Foods, Beverages, Cosmetics)
- **Image Count**: (Integer)
